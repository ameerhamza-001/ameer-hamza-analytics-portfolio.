A responsive, dark-premium personal portfolio for GitHub and GitHub Pages.

- Data Analytics
- Finance Analytics

## Skills listed in the resume
Python, MySQL, Power BI, Tableau, Excel, PowerPoint, Word, Orange, Canva and data management.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io` (or any repository).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

## Before publishing
- Update the GitHub button URL in `index.html` to your actual GitHub profile.
- Check that the email and LinkedIn URL are correct and that you want them public.
- Add screenshots, datasets, notebooks, SQL scripts and dashboard links to each project folder.
- The Sales Performance Dashboard and Customer Behaviour Analysis cards are suggested projects, not completed work. Publish them as completed only after you have done the analysis.
- For the Business Data Analysis project, add only files and findings that you personally created and can explain in an interview.
